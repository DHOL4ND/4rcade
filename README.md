# DHØL ARCADE v1.2.0

**Nine games. A livelier dashboard. Same retro-neon identity.**

DHØL ARCADE is a small browser arcade collection designed for quick sessions, simple controls, local high scores, and a strong retro-neon identity.

## Games
1. Neon Invaders — arcade shooter
2. Mystic Forest — adventure grid
3. Color Swap — match-3 puzzle
4. Skybound — platform / jetpack
5. Turbo Dash — racing
6. Pixel Snake — classic arcade
7. Star Runner — endless runner (new in v1.2.0)
8. Bubble Burst — bubble-shooter puzzle (new in v1.2.0)
9. Croak Hop — Frogger-style road/river crossing (new in v1.2.0)

## Release quality
- Responsive desktop and mobile layouts
- Touch controls on supported games
- Local high scores with `dhol_*` keys
- No account required
- No game backend required
- No external game API required
- Mobile navigation
- Game-page Escape shortcut back to the library
- Color Swap starts with a playable board and handles dead boards
- Reduced-motion support inherited from the site stylesheet

## Run locally
Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Release policy
v1.2.0 is the current stable baseline (see CHANGELOG.md for what changed since v1.1.0). Future fixes should be released as patch versions (v1.2.1, v1.2.2, etc.) rather than changing this baseline in place.
